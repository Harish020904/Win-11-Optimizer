# 1. Telemetry Reduction (Most Complained Issue)

Windows constantly sends diagnostics.

Users hate:

* telemetry
* diagnostic data
* activity tracking

### Disable Diagnostic Tracking

Run **as Administrator PowerShell**

```powershell
sc stop DiagTrack
sc config DiagTrack start=disabled
```

Disable telemetry service.

---

### Disable Tailored Experiences

Settings → Privacy → Diagnostics & Feedback

Turn OFF:

```
Tailored Experiences
View Diagnostic Data
Feedback frequency
```

---

### Disable Activity History

Settings → Privacy → Activity History

Uncheck

```
Store my activity history
Send my activity history to Microsoft
```

---

# 2. Background Apps (Huge Resource Waste)

Windows runs random UWP apps in background.

Disable globally.

Settings → Apps → Installed Apps → Advanced options.

Or registry method:

```
Computer\HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\BackgroundAccessApplications
```

Set

```
GlobalUserDisabled = 1
```

---

# 3. Startup Optimization

Most machines slow down because **Windows autostart garbage**.

Open:

```
Task Manager → Startup
```

Disable:

Common junk:

```
Microsoft Teams
Edge Update
Spotify
Discord
Adobe Updater
OneDrive (optional)
```

Startup impact improves boot drastically.

---

# 4. Remove Ads from Windows UI

Yes, Windows literally ships ads.

Disable these:

Settings → Personalization → Start

Turn OFF:

```
Show suggestions occasionally
Show recently added apps
Show recommended files
```

---

# 5. Disable Lock Screen Ads

Settings → Personalization → Lock Screen

Turn OFF:

```
Get fun facts tips tricks
```

Use **Picture**, not **Windows Spotlight**.

---

# 6. Edge Background Processes

Edge stays alive even when closed.

Disable:

Open Edge → Settings → System.

Turn OFF:

```
Startup Boost
Continue running background extensions
```

This alone reduces idle RAM.

---

# 7. Disable Widgets

Windows 11 Widgets constantly poll network.

Disable using **Group Policy**.

Run:

```
gpedit.msc
```

Go:

```
Computer Configuration
→ Administrative Templates
→ Windows Components
→ Widgets
```

Set:

```
Allow Widgets = Disabled
```

---

# 8. Disable Game Bar (If Not Gaming)

Xbox Game Bar runs background services.

Settings → Gaming → Xbox Game Bar

Turn OFF.

---

# 9. Disable Cortana

Cortana is useless for most users.

Settings → Apps → Installed Apps → Cortana

Disable startup.

---

# 10. Disable OneDrive (Optional)

Only if you **do not use cloud sync**.

Open startup:

Disable:

```
Microsoft OneDrive
```

Or uninstall.

---

# 11. File Explorer Fixes

Enable classic efficient behavior.

Open File Explorer options.

Change:

```
Open File Explorer to: This PC
```

Disable:

```
Show recently used files
Show frequently used folders
```

This stops indexing noise.

---

# 12. Disable Windows Tips

Settings → System → Notifications

Turn OFF:

```
Get tips and suggestions
Suggest ways to finish setting up
```

---

# 13. Search Indexing Reduction

Windows search indexer can hammer SSD.

Settings → Privacy → Searching Windows

Set:

```
Classic Search
```

Exclude folders like:

```
node_modules
VM folders
datasets
```

Since you're doing **ML + datasets for IDS project**, indexing those directories wastes CPU.

---

# 14. Power Optimization (Important for your Laptop)

Since your **Acer Aspire Lite uses Intel i5-12450H**, configure balanced power.

Open:

```
Control Panel → Power Options
```

Use:

```
Balanced
```

Advanced settings:

```
Processor minimum state = 5%
Processor maximum state = 100%
```

---

# 15. Disable Delivery Optimization

Windows uses your internet to update other PCs.

Settings → Windows Update → Advanced Options → Delivery Optimization

Turn OFF.
