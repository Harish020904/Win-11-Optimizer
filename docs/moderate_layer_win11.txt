# Moderate Tweaks — scope & safety model

These tweaks:

* reduce services & scheduled tasks you likely don’t need,
* remove or un-provision nonessential UWP apps,
* harden telemetry & background tasks at policy level,
* keep Windows Update, Defender, Servicing Stack, Store framework, and core runtimes intact.

If you want *absolute* system-minimal later, that’s “Ultimate / God mode” territory — we’ll cross that bridge only when you explicitly say so.

---

## 1) Telemetry & policies — stronger, policy-level control (reversible)

**Goal:** block telemetry endpoints and telemetry services via Group Policy / registry (works across reboots).

*Group Policy (Enterprise/Pro):*
Run `gpedit.msc` → Computer Configuration → Administrative Templates → Windows Components → Data Collection and Preview Builds → **Allow Telemetry** → **Enabled** → set to **0 (Security)** (Note: 0 only available on Enterprise; on Pro set to 1 or 2).

*Registry (works on Home/Pro):*

```powershell
# set telemetry to minimal
New-Item -Path "HKLM:\SOFTWARE\Policies\Microsoft\Windows\DataCollection" -Force
Set-ItemProperty -Path "HKLM:\SOFTWARE\Policies\Microsoft\Windows\DataCollection" -Name "AllowTelemetry" -Type DWord -Value 0 -Force

# disable Advertising ID
New-Item -Path "HKCU:\SOFTWARE\Microsoft\Windows\CurrentVersion\AdvertisingInfo" -Force
Set-ItemProperty -Path "HKCU:\SOFTWARE\Microsoft\Windows\CurrentVersion\AdvertisingInfo" -Name "Enabled" -Type DWord -Value 0 -Force
```

**Revert:** delete these keys or set AllowTelemetry to 1/2 as required.

## 2) Services — set to Manual/Disabled (only non-critical ones)

**Principle:** change StartupType to **Manual** first, observe 48–72 hours, then **Disabled** if no issue.

Safe-to-consider list (only if you don’t use those features):

* Xbox & Gaming: `XblAuthManager`, `XblGameSave`, `XboxGipSvc`, `XboxNetApiSvc`, `GamingServices` (if you do not play Microsoft Store games)
* OneDrive/Sync services (if you don’t use OneDrive)
* `WMPNetworkSvc` (Windows Media Player network sharing)
* `RetailDemo` (if present)
* `Fax` (if you never use fax)
* `MapsBroker` (only if you never use Maps)
* `dmwappushservice` (Device Management — for MDM-managed devices only; safe to disable for personal)
* `DiagTrack` / `dmclient` (Connected User Experiences) — already in minimal, but can enforce here.

**Commands (example):**

```powershell
$svc = @(
 "XblAuthManager","XblGameSave","XboxGipSvc","XboxNetApiSvc",
 "GamingServices","WMPNetworkSvc","RetailDemo","Fax","MapsBroker"
)
foreach ($s in $svc) {
  if (Get-Service -Name $s -ErrorAction SilentlyContinue) {
    Stop-Service -Name $s -Force -ErrorAction SilentlyContinue
    Set-Service -Name $s -StartupType Disabled
  }
}
```

**Note:** If a service is absent, the script skips it.
**Reversal:** `Set-Service -Name <servicename> -StartupType Automatic` and `Start-Service -Name <servicename>`.

## 3) Scheduled Tasks — disable annoying telemetry/telemetry-adjacent jobs

**Principle:** list matching Microsoft telemetry / Customer Experience tasks and disable them.

**List & disable (preview first):**

```powershell
# preview tasks matching telemetry/customer experience
Get-ScheduledTask | Where-Object { $_.TaskName -match "Customer|Microsoft\\Windows\\Application Experience|Maps|Customer Experience" } | Select TaskName,TaskPath

# disable some known noisy tasks (example)
Disable-ScheduledTask -TaskPath "\Microsoft\Windows\Application Experience\" -TaskName "ProgramDataUpdater" -ErrorAction SilentlyContinue
Disable-ScheduledTask -TaskPath "\Microsoft\Windows\Customer Experience Improvement Program\" -TaskName "Consolidator" -ErrorAction SilentlyContinue
```

**Always preview** the tasks before disabling.
**Reversal:** `Enable-ScheduledTask -TaskName "<name>" -TaskPath "<path>"`.

## 4) UWP App Cleanup — safe removals & un-provisioning

**Principle:** remove *noncritical* app packages (Xbox, preinstalled games, tips, 3D Viewer, Paint 3D, MixedReality) but **keep** Microsoft.Store, ShellExperienceHost, and WindowsSecurity.

**Preview removable runtime packages (example):**

```powershell
Get-AppxProvisionedPackage -Online | Select DisplayName
```

**Remove specific packages (safe list examples):**

```powershell
# remove for current user (unregister)
Get-AppxPackage -Name *Xbox* | Remove-AppxPackage -ErrorAction SilentlyContinue
Get-AppxPackage -Name Microsoft.Microsoft3DViewer | Remove-AppxPackage -ErrorAction SilentlyContinue
Get-AppxPackage -Name Microsoft.SolitaireCollection | Remove-AppxPackage -ErrorAction SilentlyContinue
Get-AppxPackage -Name Microsoft.GetHelp | Remove-AppxPackage -ErrorAction SilentlyContinue
Get-AppxPackage -Name Microsoft.MicrosoftStickyNotes | Remove-AppxPackage -ErrorAction SilentlyContinue
```

**To prevent them provisioning for new users (offline):**

```powershell
Get-AppxProvisionedPackage -Online | Where-Object { $_.DisplayName -match "Xbox|3DViewer|Solitaire|StickyNotes|GetHelp" } | ForEach-Object { Remove-AppxProvisionedPackage -Online -PackageName $_.PackageName }
```

**Caution:** DO NOT remove `Microsoft.WindowsStore` or packages with names containing `Windows.Security`/`ShellExperienceHost`/`TextInputFramework`/`Start` — they are fundamental.

**Reinstall (reversal):**

```powershell
# Reinstall default apps for current user
Get-AppxPackage -AllUsers| Foreach { Add-AppxPackage -DisableDevelopmentMode -Register "$($_.InstallLocation)\AppXManifest.xml" } 
# (Use with caution — may reinstall many things)
```

## 5) Edge + Browser background cruft

**Goal:** stop Edge/Chrome helpers running when not in use.

**Edge (recommended):**

* Edge → Settings → System → Disable **Startup boost** and **Continue running background apps**.
* Or via Edge policies if managing many machines.

**Kill background helper from auto-launch:**

```powershell
# Remove Edge background auto-launch tasks if present (example)
Get-ScheduledTask | Where-Object { $_.TaskName -match "Edge" -and $_.TaskPath -match "Microsoft\\Edge" } | Disable-ScheduledTask
```

## 6) OneDrive uninstall (if you don’t use it)

**Uninstall safely (per-user):**

```powershell
# 64-bit Windows
$OneDriveSetup = "$env:SystemRoot\SysWOW64\OneDriveSetup.exe"
& $OneDriveSetup /uninstall
```

**Reinstall:** run OneDriveSetup.exe from Microsoft or run `winget install Microsoft.OneDrive`.

## 7) Search Index / WSearch — tune, don’t kill

**Principle:** don’t disable search service globally if you use Windows Search. Instead exclude heavy folders (datasets, node_modules, VMs).

**Add exclusions:**
Settings → Privacy & Security → Searching Windows → Excluded Folders → add your datasets and development folders.

Or PowerShell:

```powershell
# Example to exclude folder from index (requires admin)
$regPath = "HKLM:\SOFTWARE\Microsoft\Windows Search\Gather\Windows\SystemIndex\Sites\Local"
# Manual edits to index require care; GUI recommended
```

If you truly never use search, you can set `WSearch` to Manual/Disabled — test first.

## 8) SysMain (Superfetch) — evaluate, then disable if harmful

**On SSDs** SysMain can be OK. If you’re seeing high I/O, set to disabled:

```powershell
Set-Service -Name "SysMain" -StartupType Disabled
Stop-Service -Name "SysMain" -Force
```

**Revert:** set to Automatic and start.

## 9) Defender tuning (don’t disable!) — exclude dev/dataset folders to reduce scans

This is safer than disabling Defender.

# Quick rollback commands (essentials)

* Restore system restore point: use System Restore UI or `rstrui.exe`.
* Re-enable services you disabled:

```powershell
Set-Service -Name "XblAuthManager" -StartupType Manual
Start-Service -Name "XblAuthManager"
```

* Re-enable scheduled tasks:

```powershell
Enable-ScheduledTask -TaskPath "\Microsoft\Windows\Application Experience\" -TaskName "ProgramDataUpdater"
```

# Drawbacks — Moderate Tweaks (Windows 11)

Below I list the concrete features you’ll sacrifice (or noticeably change) for each moderate tweak we discussed, the real-world impacts you’ll feel, severity, and how reversible the change is (short note). I’ll focus **only** on the Moderate set you approved.

---

## 1) Telemetry & policy-level control (AllowTelemetry → 0 / AdvertisingID off)

**Features lost / behavior changed**

* Automatic diagnostic submission to Microsoft (crash telemetry, feature usage).
* Some Microsoft cloud-personalization and adaptive features (minor personalization in Start/Store/Copilot-like experiences).
* Certain automated troubleshooting suggestions and remote diagnostics from MS Support may be less effective.

**Visible impacts**

* Troubleshooting with Microsoft support can take longer or require manual logs.
* Windows Insider features or some preview features may not work or may be blocked.

**Severity:** Low → Medium (affects support & insider features, not core OS).
**Reversibility:** High — change registry/GPO back or delete keys.

---

## 2) Services set to Manual/Disabled (Xbox, OneDrive, MapsBroker, Fax, WMPNetworkSvc, dmwappush, etc.)

**Features lost / behavior changed**

* Xbox/Game Pass integration, cloud saves, Game Bar overlays and recording (if those services are disabled).
* OneDrive automatic sync/“PC folder backup” stops; file-on-demand behavior changes if uninstalled.
* Offline maps auto-download and maps app features disabled.
* Windows Media Player DLNA/streaming stops.
* Fax support removed if Fax service disabled.
* Some vendor/device management push features (dmwappush) won’t run — affects MDM-managed profiles.

**Visible impacts**

* Auto-sync/backup of Desktop/Documents/Pictures to OneDrive no longer works.
* Game-related features (achievements, overlays, multiplayer NAT helpers) break.
* Any app relying on the service to start on demand might show errors until restarted.
* MDM/enterprise management may show device not fully compliant on corporate policies.

**Severity:** Low → High (depends on whether you use those features — OneDrive and MDM can be high impact).
**Reversibility:** High — set services back to Manual/Automatic and start them.

---

## 3) Scheduled task disabling (Application Experience, Customer Experience tasks)

**Features lost / behavior changed**

* Less frequent telemetry/usage sampling tasks — fewer background data collection runs.
* Some telemetry-driven maintenance tasks (like program compatibility data updates) may not execute automatically.
* Auto-repair / compatibility database updates might be delayed.

**Visible impacts**

* On rare compatibility regressions, automated program fixes may not be applied; you might need to run compatibility/repair manually.
* A small reduction in background CPU/IO.

**Severity:** Low.
**Reversibility:** High — re-enable scheduled tasks.

## 4) UWP App cleanup & un-provisioning (remove inbox apps like Xbox, Sticky Notes, 3D Viewer, Solitaire, GetHelp)

**Features lost / behavior changed**

* Those specific apps will be gone for current and future users (if you remove provisioned packages).
* Some Store-based deep links or “open in app” flows (from webpages or apps) that expect the UWP may fall back or show prompts.
* Removing “Get Help” replaces Microsoft’s built-in help app with web-based help only.

**Visible impacts**

* If you relied on Sticky Notes, Paint 3D, or 3D Viewer, they won’t be available until reinstalled.
* New user profiles created later will not auto-receive those apps (good or bad depending on your view).

**Severity:** Low → Medium (depends on which apps you remove).
**Reversibility:** Medium — re-provisioning can be cumbersome; reinstall via Store/PowerShell or re-register may be needed.

**Visible impacts**

* Faster I/O and fewer false positives for dev tools and datasets.

**Severity:** Medium (security risk depends on your environment).
**Reversibility:** High — remove exclusions.

# Cross-cutting / Less obvious drawbacks

* **Automatic updates & diagnostics still work, but some automatic self-healing behaviors rely on telemetry/scheduled tasks.** You may need to run manual fixes.
* **Enterprise management / MDM signals:** If device is or will be enrolled in corporate management, some disabled services or policies can make the device non-compliant.
* **App compatibility:** Some Win32 or UWP apps expect certain background services/tasks; they might log errors or behave oddly until you re-enable the service.
* **User convenience vs. security tradeoffs:** Excluding Defender/Indexing improves performance but increases risk or reduces productivity (search).
* **Hidden dependencies:** A few Microsoft or third-party features (e.g., Office “auto-recover” cloud features, Teams background sync) rely on background tasks — they will degrade in subtle ways.

# Practical risk classification & recommendation (quick)

* **Low risk / high reward (safe to do for most power users):** disabling tips, Widgets, Edge startup boost, Start suggestions, Lock-screen Spotlight, startup apps.
* **Medium risk (do with care & test):** disabling SysMain, excluding Defender paths, un-provisioning nonessential UWP apps, disabling telemetry via registry/GPO.
* **Higher risk (only if you know you don’t need them):** uninstalling OneDrive, disabling MDM/dmwappush for managed devices, removing OEM utilities you actually use.
